# Visual Analysis

Analyze evidence at three levels.

## Page System

- container width, gutters, breakpoints, and first-view height;
- section order, rhythm, backgrounds, and transitions;
- recurring typography, colors, radii, borders, shadows, and media treatment.

## Section Composition

- grid structure and alignment anchors;
- content order and relative emphasis;
- whitespace, overlap, crop, and aspect ratios;
- repeated components versus one-off signature elements.

## Components and Behavior

- control type, size, states, and focus behavior;
- likely responsive collapse or reordering;
- motion implied by sequence, layering, or interaction cues;
- data and copy that are visible versus missing.

Record measurements as approximate ranges unless exact design data exists. Separate visible facts from implementation choices and unresolved behavior.
