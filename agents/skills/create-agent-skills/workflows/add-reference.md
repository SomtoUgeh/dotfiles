# Add a Reference

Read [skill structure](../references/skill-structure.md). Resolve the target from the user request or loaded skill; ask only if the target is unknown.

1. Read the entrypoint and related references fully. Identify reusable knowledge that is missing; keep workflow-specific detail in the workflow when clearer.
2. Verify external facts against primary sources and relevant versions.
3. Write a focused Markdown reference with decision criteria, examples, sources, and limitations. Avoid duplicating maintained guidance elsewhere.
4. Link it directly from the entrypoint and from workflows that need it. Resolve relative links from each containing file.
5. Check every link and exercise any runnable example. Verify that a reader following the original route reaches the new resource.

Complete when the resource answers the intended need and the entrypoint, callers, and examples agree.
