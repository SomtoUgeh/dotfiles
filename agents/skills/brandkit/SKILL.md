# Brand-kit image generation

Create one coherent brand world in a presentation-ready image. Establish the
strategy and logo idea before choosing panels or decorative details.

Read [references/art-direction-guide.md](references/art-direction-guide.md) when
you need visual-mode options, logo concept methods, panel recipes, prompt details,
or the full quality checklist. The entrypoint below controls the workflow.

## Intake

Use information the user already supplied. Infer ordinary art-direction choices
when the brief is incomplete; ask only when a missing answer would materially
change the identity:

- brand name and category
- audience and desired impression
- core metaphor or differentiator
- required applications or panels
- references and constraints

When references exist, inspect their grid, density, type hierarchy, image
treatment, and color logic. Do not copy a logo, slogan, composition, or unique
asset.

## Build the concept

Write a compact internal direction before generating:

1. **Position:** what the brand represents for whom.
2. **Metaphor:** one ownable idea tied to the product or culture.
3. **Mark:** how form and metaphor combine in a simple repeatable logo.
4. **System:** palette, typography mood, image direction, and texture.
5. **Applications:** panels that prove the system works in context.

Avoid generic gradients, meaningless blobs, random floating icons, dense fake
UI, and unrelated mockups. Keep one recognizable mark and one disciplined visual
language across every panel.

## Compose the board

Unless the user specifies otherwise, use one 3 x 3 overview board in a 4:3 or
16:10 frame. Use strong gutters, deliberate negative space, sparse readable text,
and a consistent presentation canvas.

Default panel set:

1. logo cover
2. mark construction or concept
3. digital application
4. tagline or brand essence
5. color system
6. typography
7. physical application
8. image direction
9. system detail

Change the grid or panel set when the brief calls for it. Mockups should prove
identity behavior, not imitate a full product demo.

## Generate

Use the available image-generation tool. Include the complete art direction in
one cohesive prompt: strategy, metaphor, logo construction, layout, panels,
palette, typography, image treatment, applications, and exclusions. For edits,
include the target image through the tool's supported reference mechanism.

Inspect the result before presenting it. Regenerate or edit when the mark changes
between panels, text becomes illegible, the grid loses hierarchy, applications
feel unrelated, or the output resembles a generic moodboard.

## Output gate

The result must communicate the same identity across logo, type, color, imagery,
and applications. It should be sparse enough to scan, detailed enough to guide
implementation, and visually specific to the supplied brand.
