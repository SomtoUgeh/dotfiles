# API Shield

API Shield discovers API endpoints, validates request schemas and JWTs, supports client certificate policies, and identifies suspicious API usage. A valid token or schema does not prove that a caller may access an individual object: enforce object and function authorization in the application.

Read [configuration](configuration.md) for rollout, [API](api.md) for current token and Rules language interfaces, [patterns](patterns.md) for policy examples, and [gotchas](gotchas.md) for failure diagnosis.

Availability and quotas vary by feature and subscription. Check the [current product documentation](https://developers.cloudflare.com/api-shield/) and the target zone's entitlement before provisioning.
