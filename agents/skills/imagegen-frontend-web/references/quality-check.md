# Reference Image Quality Check

## Clarity

- Required content and action are easy to find.
- Headline width and wrapping feel intentional.
- Section boundaries and reading order are visible.
- Dense UI is large enough to inspect.

## Coherence

- Palette, typography, surfaces, and recurring controls match across views.
- Product names and example data stay consistent.
- Media treatment changes only for a deliberate reason.

## Composition

- Section layouts do not repeat the same split mechanically.
- Whitespace and density reflect the content.
- Grids have intentional occupancy without forced filler.
- Decorative effects support the focal hierarchy.

## Implementation Readiness

- Component boundaries and alignment anchors can be inferred.
- Media aspect ratios and crops are clear.
- Responsive behavior has an obvious plausible path.
- No generated text is required as authoritative product copy.

Regenerate any view that fails on a high-salience criterion rather than explaining around an unusable image.
