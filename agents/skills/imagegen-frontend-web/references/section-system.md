# Multi-Image Section System

## Coverage

List the required page sections and group only those that remain readable together. Use focused images for dense navigation, complex forms, data tables, or signature interactions.

## Continuity

Repeat the same:

- font families and relative scale;
- palette and contrast logic;
- border, radius, shadow, and material language;
- navigation and recurring control treatment;
- content model and product naming.

Vary:

- composition anchor;
- media scale and crop;
- background mode;
- section density;
- direction of visual movement;
- CTA placement when the flow supports it.

## Prompt Handoff

Each image prompt should name the page, section purpose, preceding and following context, fixed design tokens, target viewport, required content, and the one composition change for that view.

Generate images sequentially when continuity matters. Inspect each result before prompting the next so defects do not propagate.
